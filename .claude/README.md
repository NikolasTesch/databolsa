# .claude/

Configuração do Claude Code para este repositório.

- `settings.json` — configurações versionadas, compartilhadas com o time.
- `settings.local.json` — overrides locais por máquina (ignorado pelo git).
- `commands/` — slash commands customizados do projeto (um `.md` por comando).
- `agents/` — subagentes customizados do projeto (um `.md` por agente).

O guia de operação fica em [`../CLAUDE.md`](../CLAUDE.md).
